53 WEST 53 — CINEMATIC MEDIA DESIGN PORTFOLIO
Designer credit: Adnan Khan

HOW TO USE
1. Open index.html in a browser to preview.
2. Deploy the folder contents to Vercel as a static site (Framework Preset: Other; no build command).
3. Alternatively upload the entire folder to Netlify Drop.

FILES
index.html — single-page website
styles.css — responsive design and animations
script.js — gallery, full-screen image viewer, keyboard/swipe navigation
assets/ — 19 optimized WEBP images derived from the supplied 19-page portfolio PDF plus supplied portrait

IMPORTANT
The official 53W53 project is credited separately and linked externally for attribution.
The website does NOT embed the official third-party brochure or claim architectural authorship.
Images from the user's portfolio may themselves incorporate third-party renderings/photos; confirm publication rights before going live.
Change designer text or other credits in index.html if necessary.
Works without a server or API; Google Fonts need internet connectivity.
